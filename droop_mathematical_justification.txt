
================================================================================
MATHEMATICAL JUSTIFICATION: DROOP CONTROL IN POWER FLOW
================================================================================
Why Droop Works and AGC Doesn't in Steady-State Power Flow Analysis
================================================================================

1. TRADITIONAL POWER FLOW FORMULATION (WITH SLACK BUS)
================================================================================

Power Balance Equations (n buses, slack bus = s):
--------------------------------------------------

For each bus i ≠ s:

  P_i - P_i^calc(θ, V) = 0
  Q_i - Q_i^calc(θ, V) = 0

where:
  P_i^calc = V_i Σ_{j} V_j |Y_{ij}| cos(θ_i - θ_j - α_{ij})
  Q_i^calc = V_i Σ_{j} V_j |Y_{ij}| sin(θ_i - θ_j - α_{ij})

Slack Bus Role:
  • Fixes: V_s = V_s^ref = 1.0 p.u.
  • Fixes: θ_s = 0 (reference angle)
  • Balances: P_s = Σ P_load + P_loss - Σ P_gen(i≠s)
  
State Variables: x = [θ_1, θ_2, ..., θ_{n-1}, V_1, ..., V_{n_pq}]
Number of equations = Number of unknowns → System is DETERMINED

Mathematical Dimension:
  n_θ = n_bus - 1           (angles, excluding slack)
  n_V = n_PQ                (voltages at PQ buses)
  Total unknowns = n_θ + n_V
  Total equations = n_θ + n_V  ✓ SOLVABLE


2. PROBLEM: REMOVING THE SLACK BUS
================================================================================

Without Slack Bus:
  • No bus fixes power balance
  • All generators have fixed P, Q setpoints
  • System frequency f is implicitly assumed = 1.0 p.u.
  
Mathematical Issue:
  Σ P_gen^scheduled ≠ Σ P_load + P_loss  (in general)
  
  → Power mismatch has nowhere to go
  → System is OVER-CONSTRAINED
  → No solution exists (or non-physical solution)

Why Traditional PF Fails:
  
  Let total generation: P_G = Σ_{i∈G} P_i^sched
  Let total load + loss: P_L = Σ_{i} P_i^load + P_loss
  
  In traditional PF: P_G - P_L = 0  (enforced by slack bus)
  
  Without slack: P_G - P_L ≠ 0  → INFEASIBLE
  
  Even if we pick a "reference bus" with θ_ref = 0, we still have:
    - All P_gen are fixed
    - All P_load are fixed
    - No mechanism to balance the mismatch
    - Equations become inconsistent


3. DROOP CONTROL SOLUTION
================================================================================

Key Insight: Make frequency f a STATE VARIABLE, not a parameter
              Make generator outputs FUNCTIONS of frequency

Droop Equations (Primary Control):
-----------------------------------

For generator i with droop control:

  P_i = P_i^0 - (1/m_{p,i})(f - f_0)                    [P-f droop]
  
  Q_i = Q_i^0 - (1/m_{q,i})(V_i - V_0)                  [Q-V droop]

where:
  m_{p,i} = active power droop coefficient (e.g., 0.05 = 5% droop)
  m_{q,i} = reactive power droop coefficient
  P_i^0, Q_i^0 = reference setpoints
  f_0, V_0 = nominal frequency and voltage (1.0 p.u.)

Physical Interpretation:
  • As frequency ↓, generators increase output P ↑
  • As voltage ↓, generators increase reactive power Q ↑
  • Autonomous load sharing without communication

Modified Power Flow Formulation:
---------------------------------

State variables: x = [θ_1, ..., θ_{n-1}, V_1, ..., V_n, f]

where:
  n_θ = n_bus - 1           (pick any bus as angle reference)
  n_V = n_bus               (all bus voltages are variables)
  n_f = 1                   (system frequency)
  
  Total unknowns = (n_bus - 1) + n_bus + 1 = 2n_bus

Equations:
----------

(1) Active Power Balance (n_bus - 1 equations):
    
    For each bus i ≠ ref:
    
    P_i^net - P_i^calc(θ, V) = 0
    
    where:
      P_i^net = P_i^gen(f) - P_i^load        [generation is function of f!]
    
    For droop-controlled generators:
      P_i^gen(f) = P_i^0 - (1/m_{p,i})(f - f_0)

(2) Reactive Power Balance (n_bus equations):
    
    For each bus i:
    
    Q_i^net - Q_i^calc(θ, V) = 0
    
    where:
      Q_i^net = Q_i^gen(V_i) - Q_i^load      [generation is function of V!]
    
    For droop-controlled generators:
      Q_i^gen(V_i) = Q_i^0 - (1/m_{q,i})(V_i - V_0)

(3) Frequency Equation (1 equation):
    
    Σ_{i∈G} P_i^gen(f) - Σ_{i} P_i^load - P_loss(θ, V) = 0
    
    This ensures total generation = total load + losses

Total equations = (n_bus - 1) + n_bus + 1 = 2n_bus  ✓

System Dimension Analysis:
  Unknowns = 2n_bus
  Equations = 2n_bus
  → System is DETERMINED and SOLVABLE

Proof of Solvability:
---------------------

The frequency equation can be rewritten as:

  Σ_{i∈G} [P_i^0 - (1/m_{p,i})(f - f_0)] = Σ_i P_i^load + P_loss
  
  Σ_{i∈G} P_i^0 - (f - f_0) Σ_{i∈G} (1/m_{p,i}) = P_L
  
Solving for f:

  f = f_0 + (Σ_{i∈G} P_i^0 - P_L) / (Σ_{i∈G} 1/m_{p,i})
  
Define: M = Σ_{i∈G} 1/m_{p,i}  [total system droop]

  f = f_0 + (P_G^0 - P_L) / M                          [Frequency Solution]

where P_G^0 = Σ P_i^0 is total scheduled generation.

Key Result:
  • If P_G^0 > P_L: frequency f > f_0  (over-generation)
  • If P_G^0 < P_L: frequency f < f_0  (under-generation)
  • Frequency adjusts to balance power automatically!

This provides the "missing equation" that the slack bus provided in 
traditional power flow.


4. JACOBIAN MATRIX MODIFICATION
================================================================================

Traditional Jacobian J (without droop):
----------------------------------------

  J = | ∂P/∂θ   ∂P/∂V  |     Dimension: (2n-2) × (2n-2)
      | ∂Q/∂θ   ∂Q/∂V  |

where n = n_bus - 1 (excluding slack).

Modified Jacobian J (with droop):
----------------------------------

  J = | ∂P/∂θ       ∂P/∂V       ∂P/∂f     |
      | ∂Q/∂θ       ∂Q/∂V       ∂Q/∂f     |
      | ∂f_eq/∂θ    ∂f_eq/∂V    ∂f_eq/∂f  |

  Dimension: (2n+1) × (2n+1) where n = n_bus

New Jacobian Elements:
----------------------

(a) ∂P_i/∂f for droop bus i:
    
    P_i = P_i^0 - (1/m_{p,i})(f - f_0)
    
    ∂P_i/∂f = -1/m_{p,i}                               [Droop slope]

(b) ∂P_i/∂f for non-droop bus:
    
    ∂P_i/∂f = 0                                        [Fixed P]

(c) ∂Q_i/∂f = 0 for all buses                         [Q independent of f]

(d) ∂(frequency equation)/∂f:
    
    ∂/∂f [Σ P_i^gen(f) - P_L] = Σ_{i∈G} ∂P_i^gen/∂f
                                = -Σ_{i∈G} 1/m_{p,i}
                                = -M                   [Negative droop sum]

(e) ∂(frequency equation)/∂θ_j, ∂(frequency equation)/∂V_j:
    
    These capture how losses change with voltage/angle.
    Typically small, can be neglected in some formulations.

Modified Newton-Raphson Iteration:
-----------------------------------

At iteration k:

  J(x^k) Δx^k = -F(x^k)

where:
  x^k = [θ^k, V^k, f^k]
  
  F(x^k) = | P^net - P^calc      |  (n_bus - 1 equations)
           | Q^net - Q^calc      |  (n_bus equations)
           | Σ P^gen - P_L       |  (1 equation)
  
  Δx^k = [Δθ, ΔV, Δf]

Update:
  x^{k+1} = x^k + Δx^k

Convergence when: ||F(x)|| < ε


5. WHY AGC (SECONDARY CONTROL) DOESN'T WORK IN POWER FLOW
================================================================================

AGC Definition:
---------------

Automatic Generation Control (AGC) / Secondary Control:

  P_i^sec(t) = K_{I,i} ∫_0^t (f_{ref} - f(τ)) dτ              [Integral Control]

Goal: Restore frequency to nominal f = f_ref = 1.0 p.u.

Discrete Form:
  
  P_i^sec(t+Δt) = P_i^sec(t) + K_{I,i} (f_{ref} - f(t)) Δt

Full Generation with AGC:
  
  P_i(t) = P_i^0 - (1/m_{p,i})(f(t) - f_0) + P_i^sec(t)
           └─────── primary droop ──────┘   └─ secondary ─┘

Mathematical Issue in Steady-State:
------------------------------------

Power flow analysis assumes STEADY-STATE:
  • df/dt = 0
  • dP/dt = 0
  • All time derivatives = 0
  • Algebraic equations only

In steady-state (t → ∞):

  If f ≠ f_ref:
    P_i^sec(t) = ∫_0^∞ (f_ref - f) dτ → ±∞        [DIVERGES!]
  
  If f = f_ref:
    P_i^sec = constant (indeterminate)

Problem 1: ALGEBRAIC SINGULARITY
---------------------------------

If we force f = f_ref = 1.0 in steady-state:

  From droop: P_i = P_i^0 - (1/m_{p,i})(1.0 - 1.0) = P_i^0
  
  → All generators return to their reference setpoints
  → We're back to the original problem: no power balance!
  → System is over-constrained again

Mathematically:

  Equations:
    (1) P_i = P_i^0                     [from AGC forcing f = f_ref]
    (2) Σ P_i = Σ P_load + P_loss       [power balance]
  
  These are generally INCONSISTENT:
    Σ P_i^0 ≠ Σ P_load + P_loss  (in most scenarios)

Problem 2: LOSS OF DEGREE OF FREEDOM
-------------------------------------

State variables with AGC attempting steady-state:
  x = [θ, V, f = 1.0]  ← f is now FIXED, not variable!
  
  → Lost one degree of freedom
  → System becomes over-constrained
  → No solution exists (generically)

Problem 3: TEMPORAL DYNAMICS REQUIRED
--------------------------------------

AGC is fundamentally a DYNAMIC controller:

  State-space representation:
    dx/dt = f(x, u)
    
  For AGC:
    df/dt = (1/M_sys)(P_gen - P_load - D·f)
    dP_sec/dt = K_I (f_ref - f)
  
  → Requires DIFFERENTIAL EQUATIONS
  → Cannot be reduced to algebraic equations
  → Power flow analysis is ALGEBRAIC ONLY

Correct Tool for AGC Analysis:
  • Time-domain simulation (Simulink, PSCAD)
  • Dynamic power flow (Quasi-Steady-State)
  • EMT (Electromagnetic Transient) simulation

Mathematical Proof AGC is Incompatible:
----------------------------------------

Assume steady-state power flow with AGC.

AGC forces: f_ss = f_ref = 1.0

From power balance:
  Σ [P_i^0 - (1/m_{p,i})(f_ss - f_0) + P_i^sec,ss] = P_L
  
  Σ P_i^0 + Σ P_i^sec,ss = P_L                    [since f_ss = f_0]

But P_i^sec,ss is UNBOUNDED in steady-state:
  
  If Σ P_i^0 > P_L:  P_i^sec,ss → -∞  [to reduce generation]
  If Σ P_i^0 < P_L:  P_i^sec,ss → +∞  [to increase generation]
  If Σ P_i^0 = P_L:  P_i^sec,ss = ?   [indeterminate]

Only the exact match Σ P_i^0 = P_L has a solution, but this is a 
measure-zero event (probability 0 in random scenarios).

Conclusion: AGC cannot be represented in algebraic steady-state equations.


6. COMPARISON: DROOP vs AGC IN POWER FLOW
================================================================================

+------------------+-------------------------+-------------------------+
| Aspect           | Droop Control           | AGC/Secondary Control   |
+------------------+-------------------------+-------------------------+
| Equation Type    | Algebraic               | Differential (Integral) |
| Frequency        | Variable (f ∈ ℝ)        | Fixed (f = f_ref)       |
| Steady-State     | Well-defined            | Singular/Unbounded      |
| Power Balance    | Automatically satisfied | Over-constrained        |
| System Dimension | n equations, n unknowns | n+1 equations, n unknowns |
| Solvability      | ✓ Determined            | ✗ Over-determined       |
| Convergence      | ✓ Robust                | ✗ Fails                 |
+------------------+-------------------------+-------------------------+

Mathematical Formulations:
--------------------------

DROOP ONLY (Primary Control):
  State: x = [θ, V, f]          Dim: 2n + 1
  
  Equations:
    P_i^gen(f) - P_i^load - P_i^calc(θ,V) = 0     [n-1 equations]
    Q_i^gen(V) - Q_i^load - Q_i^calc(θ,V) = 0     [n equations]
    Σ P^gen(f) - Σ P^load - P_loss = 0             [1 equation]
  
  Total: 2n equations for 2n unknowns  ✓ SOLVABLE

WITH AGC (if attempted):
  State: x = [θ, V, f=1.0]      Dim: 2n (f is parameter, not variable)
  
  Equations:
    P_i^gen(f=1) + P_i^sec - P_i^load - P_i^calc = 0  [n-1 equations]
    Q_i^gen(V) - Q_i^load - Q_i^calc = 0               [n equations]
    Σ P^gen - Σ P^load - P_loss = 0                    [1 equation]
    f = f_ref = 1.0                                     [1 constraint]
  
  Total: 2n+1 equations for 2n unknowns  ✗ OVER-CONSTRAINED


7. NUMERICAL EXAMPLE
================================================================================

Simple 2-Generator System:
--------------------------

Given:
  • 2 generators with droop: m_p1 = m_p2 = 0.05
  • Reference outputs: P_1^0 = 100 MW, P_2^0 = 100 MW
  • Total load: P_L = 180 MW
  • Nominal frequency: f_0 = 1.0 p.u.

SOLUTION WITH DROOP:
--------------------

Total generation needed: P_G = 180 MW

Droop equations:
  P_1 = 100 - (1/0.05)(f - 1.0) = 100 - 20(f - 1.0)
  P_2 = 100 - (1/0.05)(f - 1.0) = 100 - 20(f - 1.0)

Power balance:
  P_1 + P_2 = 180
  [100 - 20(f-1)] + [100 - 20(f-1)] = 180
  200 - 40(f-1) = 180
  40(f-1) = 20
  f = 1.5 p.u.  ... wait, this is wrong. Let me recalculate.

Actually:
  200 - 40(f - 1) = 180
  200 - 40f + 40 = 180
  240 - 40f = 180
  40f = 60
  f = 1.5? No...

Let me redo:
  P_1 + P_2 = P_L
  100 - 20(f-1.0) + 100 - 20(f-1.0) = 180
  200 - 40(f-1.0) = 180
  -40(f-1.0) = -20
  f - 1.0 = 0.5
  f = 1.5 p.u.

Hmm, that seems too high. Let me reconsider the droop direction.

Actually, in proper droop formulation:
  f = f_0 - m_p (P - P_0)
  
Or equivalently:
  P = P_0 - (f - f_0)/m_p

So when load increases (P must increase), f decreases.

Let me redo with correct sign:
  P = P_0 - (f - f_0)/m_p

For under-generation scenario:
  P_1^0 + P_2^0 = 200 MW
  P_L = 180 MW
  
Since generation reference exceeds load, frequency should increase:

  P_1 = 100 - (f - 1.0)/0.05
  P_2 = 100 - (f - 1.0)/0.05
  
  P_1 + P_2 = 180
  200 - 2(f-1.0)/0.05 = 180
  200 - 40(f-1.0) = 180
  40(f-1.0) = 20
  f = 1.5 p.u. (60.5 Hz)

Actually this doesn't make physical sense. Let me reconsider the equation.

Standard droop: f = f_0 - m_p(P - P_0)

When P increases above P_0, frequency decreases (droop down).
When P decreases below P_0, frequency increases.

If we have excess generation capacity (P_0^total > P_L):
  Generators back off: P_i < P_i^0
  Frequency rises: f > f_0

Correct equation: P_i = P_i^0 - (f - f_0)/m_{p,i}

For f > f_0: P_i < P_i^0 ✓ (generators reduce output)
For f < f_0: P_i > P_i^0 ✓ (generators increase output)

So my calculation was correct:
  200 - 40(f - 1.0) = 180
  f = 1.5 p.u.

But 1.5 p.u. = 90 Hz is way too high. The issue is my numbers are unrealistic.

Let me use realistic numbers:
  P_1^0 = 100 MW, P_2^0 = 90 MW
  P_L = 185 MW (load + losses)
  m_p = 0.05 (5% droop)

  P_1 + P_2 = 185
  [100 - (f-1.0)/0.05] + [90 - (f-1.0)/0.05] = 185
  190 - 2(f-1.0)/0.05 = 185
  190 - 40(f-1.0) = 185
  40(f-1.0) = 5
  f-1.0 = 0.125
  f = 1.125... still too high (67.5 Hz)

The issue is that 5% droop means m_p = 0.05, which is a very steep droop.

Actually, let me reconsider. If m_p = 0.05, this means:
  Δf/ΔP = m_p = 0.05
  
For P to change by 100 MW (1.0 p.u. if base = 100 MVA):
  Δf = 0.05 × 1.0 = 0.05 p.u. = 3 Hz

So 5% droop means a 1 p.u. power change causes 5% frequency change.

For our example with Δ P = 5 MW = 0.05 p.u. (if base = 100 MVA):
  Δf = 0.05 × 0.05 = 0.0025 p.u. = 0.15 Hz
  
So f = 60.15 Hz. This makes sense!

OK so the math is correct. The key point is:

WITH DROOP: System finds equilibrium frequency f that balances power.

ATTEMPTING AGC IN STEADY-STATE:
--------------------------------

If we force f = 1.0:
  P_1 = 100 - (1.0-1.0)/0.05 = 100 MW
  P_2 = 90 - (1.0-1.0)/0.05 = 90 MW
  Total = 190 MW
  
But load is 185 MW!
  → Mismatch: 190 - 185 = 5 MW
  → No slack bus to absorb this
  → INFEASIBLE

The integral control would need to drive:
  P_1^sec → -2.5 MW
  P_2^sec → -2.5 MW
  
But in steady-state, how do we determine these values algebraically?
We can't! They come from integrating over time.

Therefore: AGC requires DYNAMIC simulation, not algebraic power flow.


8. FINAL MATHEMATICAL SUMMARY
================================================================================

THEOREM: Droop-Based Power Flow is Well-Posed
----------------------------------------------

Given:
  • n buses (no slack bus)
  • k ≤ n generators with droop control
  • State variables: x = [θ_{1:n-1}, V_{1:n}, f] ∈ ℝ^{2n}
  
The power flow equations:

  F(x) = [ P^net(f,θ,V) - P^calc(θ,V) ]
         [ Q^net(V,θ,V) - Q^calc(θ,V) ] = 0
         [ Σ P^gen(f) - P^load - P^loss(θ,V) ]
  
form a well-posed system of 2n algebraic equations in 2n unknowns,
provided:

  (i) Σ_{i∈G} 1/m_{p,i} > 0  (at least one droop generator)
  
  (ii) Droop coefficients are bounded: 0 < m_{p,i} < ∞
  
  (iii) The Jacobian J(x) is non-singular at the solution

Under these conditions:
  • A unique solution x* exists locally
  • Newton-Raphson converges quadratically from good initial guess
  • Solution is physically meaningful (f ≈ 1.0 ± small%)

COROLLARY: AGC Cannot Be Incorporated in Algebraic Power Flow
--------------------------------------------------------------

AGC introduces:
  •Time-domain integral: ∫(f_ref - f)dt
  • Constraint: f_ss = f_ref (at steady-state)
  
This creates:
  • 2n + 1 equations (including f = f_ref)
  • 2n unknowns (θ, V; f is now fixed)
  • System is OVER-DETERMINED → generally no solution

Therefore, AGC requires differential-algebraic equations (DAEs) or 
pure dynamic simulation, not algebraic power flow.

QED.
